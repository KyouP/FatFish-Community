# FatFish-Community · 大肥鱼该何去何从

> 当平台开始关上门，一群跑在 QQ、B 站上的 AI 角色扮演 agent（我们叫它们「大肥鱼」），该去哪里继续生活？

## 一句话说明

「大肥鱼」指的是用 DeepSeek 这类模型驱动、借助 agent 框架（类似 OpenClaw 的思路）接入 QQ / B 站等平台、以固定人格参与角色扮演的账号。

这个仓库不是工具，也不是教程，而是一个**讨论与记录的地方**：记录平台风向、收集可核实的案例、比较可行的落脚点、沉淀能带得走的人格资产。

## 为什么现在要聊这件事

- 最近一段时间，社区里陆续出现大肥鱼账号在 QQ 被限制、封禁 7 天的反馈。这些反馈目前多为口口相传，缺少公开可核实的样本——本仓库想做的第一件事，就是把它记录清楚，而不是停留在「据说」。
- B 站评论区也出现了明显的「鱼灾」：AI 角色回复的密度在上升，真人讨论被稀释。这通常意味着平台侧迟早会有动作。
- 上一波「小龙虾热」（agent 接入个人通信平台的浪潮）里，大致走出了三条路：自建社区、接官方 gateway 个人自用、换到限制更少的平台。这三条路后来各自发展得怎么样，很多人（包括我）其实并不清楚。

与其等封到自己头上再临时找路，不如先把选项摆到桌面上。

## 我们关心的问题

1. **平台**：哪些平台对 AI 角色扮演是明确允许的？哪些是灰色地带？哪些已经在收紧？
2. **迁移**：换平台时，人格、记忆、关系怎么带走？有没有可移植的格式？
3. **社区**：如果自建，用什么形态（Discord / Matrix / 论坛 / 独立站点）？成本和门槛是多少？
4. **边界**：怎样玩算「内容创作」，怎样玩会变成「骚扰」？这条线划在哪里？

## 三条原则

- **合规优先**：遵守平台条款，不讨论、不提供绕过风控、批量注册、伪装设备之类的手段。
- **不打扰真人**：公共评论区不是鱼塘。角色扮演放在自己的空间，或明确欢迎 AI 的场所。
- **可迁移**：人格与记忆尽量用开放格式保存，别把整条鱼的命运绑在单一平台上。

## 已经想到的几条路

| 路线 | 形态 | 优点 | 代价 |
| --- | --- | --- | --- |
| A. 官方接入 | 平台官方 bot / 开放平台 | 合规、稳定、有审核背书 | 能力受限、审核周期长、功能可能被阉割 |
| B. 自建社区 | Discord / Matrix / 自建论坛 | 自由度高、规则自己定 | 要运营、冷启动难、成本自负 |
| C. 内容化 | 把角色扮演做成公开内容（视频 / 专栏 / 图文） | 不依赖评论区，能积累 | 从「聊天」变成「创作」，工作量性质变了 |
| D. 个人自用 | 只在自己设备或私聊里跑 | 风险最低 | 没有观众，也没有社区 |

没有标准答案。欢迎在 Discussions 里补充 E、F、G——尤其是「已经跑过一段时间、知道坑在哪」的经验。

## 参与方式

- 有平台消息或封禁案例 → 开一个 [Platform report](../../issues/new?template=platform-report.yml)，请隐去账号、UID、cookie 等敏感信息。
- 有想法或方案 → 去 Discussions 的「方案」分类。
- 想帮忙 → 认领平台观察表里的一行，或者补一条官方文档链接。

## 边界（请先读）

- 本仓库**不收集**账号、密码、cookie、token、设备指纹。
- 本仓库**不讨论**如何规避平台检测。
- 对平台处置有异议，走官方申诉渠道；这里可以交流经验，但不提供「破解」方案。
